# Findings

The findings and unverified items this repository's documents name, from the project's findings register.
Each heading's anchor is the id in lower case (`#f-0280`). A finding is a defect, gap or risk the project has
recorded; an unverified item is an assumption still to be checked. An open blocker or high finding is listed
without its description until the release that closes it.

Generated by `python3 tools/findings.py --digest`; do not edit it by hand.
